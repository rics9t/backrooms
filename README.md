# Backrooms Found Footage (Android/PojavLauncher Edition)

> **Note:** This is a modified version of the original "Backrooms Found Footage" mod by **SpacePotato**. It has been tweaked (shaders are removed) to ensure compatibility with Android devices running Minecraft Java Edition via launchers like **PojavLauncher**.

## About
The **Backrooms Found Footage** mod turns Minecraft into a terrifying, immersive horror experience, mimicking the VHS style of the popular Backrooms "Found Footage" series. 

**Original Mod Features:**
* Immersive "Found Footage" camera effects.
* Terrifying new entity (skinwalker) and mechanics.
* Generation of the Backrooms levels (Level 0, Poolrooms, etc.).

**Android Modifications:**
* **Shader Compatibility:** Adjusted rendering methods to prevent crashes on mobile GPUs (SHADERS ARE COMPLETELY REMOVED FROM THIS VERSION!).
* **Lights:** Since shaders are removed from this modification its highly recommended to download a dynamic lights mod or a flashlight mod. (flashlight in this version of mod DOESN'T WORK!)

##  Installation Guide (PojavLauncher)

### Prerequisites
* **PojavLauncher** installed on your Android device. (Testing was on the original Pojav Launcher.)
* **Fabric** (Ensure you have the correct mod loader version installed: Fabric 1.20.1).
### Mods you will need
* [**Geckolib**](https://modrinth.com/mod/geckolib) (Fabric 1.20.1)
* [**Simple Voice Chat**](https://modrinth.com/plugin/simple-voice-chat/version/fabric-1.20.1-2.6.11) (you need this exact version i think)
* [**Fabric API**](https://modrinth.com/mod/fabric-api) (Fabric 1.20.1)
* [**Sound Physics Remastered**](https://modrinth.com/mod/sound-physics-remastered/versions) (optional, Fabric 1.20.1)
